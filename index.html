TaqSim course: water allocation in the Zarafshan basin

TaqSim is a Python tool for simulating water allocation: connect river inflows, reservoirs, canals and users, then follow where the water goes and who goes short. This course uses TaqSim v0.1.4 through notebooks and games.

New? Start with setup · Already ready? Open the course steps

Welcome. This folder holds everything you need for the hands-on part of the course. You run the exercises in your web browser, on Google's free Colab service. Nothing has to be installed on your computer.

Before the course: three things to do (15 minutes)

1. Get a Google account. If you already have a Gmail address, you can use it. If not, create one at accounts.google.com. Google may ask for a phone number to confirm it is you.

2. Open the first notebook. Click this button:

A page with text and grey boxes of code opens. This is a notebook. Each grey box is a step you can run.

3. Run it. In the menu at the top, choose Runtime → Run all. The first box installs the model software, which takes about a minute. Then a drawing of a small river system appears, a table, and a chart. If you see those, you are ready for the course.

If Colab asks "Run anyway?" because the notebook was not written by Google, click Run anyway. That is normal.

Trying the AI helper (10 minutes, optional but recommended)

Colab has a built-in AI assistant called Gemini. In the course you will use it to change water models by describing what you want in plain words. To try it:

  1. Click the blue Gemini button at the bottom of the page.

  2. Copy this sentence into the chat and send it:

    Find the smallest canal share, in steps of 1 percent, for which the farm has no shortage in any of the three years. Use the run() function.

  3. Read Gemini’s proposed code. Accept and execute inserts and runs it; Accept inserts it for you to run; Deny discards it. Some interfaces instead offer Insert. You can also copy the code into + Code and run it. The right answer is 9 percent.

If that worked, you have done everything the course needs. More tasks for Gemini are in the notebook itself.

ChatGPT and the optional AI Sider sidebar

ChatGPT and Gemini web officially support Uzbekistan. See OpenAI's supported countries and Google's supported countries. This confirms provider eligibility, not access on the workshop Wi-Fi: local connectivity without VPN and extension installation still need to be checked before the workshop.

Use AI Sider: ChatGPT + DeepSeek + Gemini, offered by zenttranslate. This optional Chrome extension displays the providers' own websites beside your notebook. It is a different product from Sider.ai. No separate extension account is required; sign in to the provider you choose. A free ChatGPT account supplies normal ChatGPT assistance and remains subject to its usual limits. No paid subscription or API key is needed for these exercises.

  1. In desktop Chrome, open the exact AI Sider Chrome Web Store listing, check that the publisher is zenttranslate, choose Add to Chrome and review the requested permissions. If already installed, open it from the Extensions menu (the puzzle icon).
  2. Open the sidebar beside your Colab notebook, select ChatGPT or Gemini, and sign in to that provider. For ChatGPT, choose Sign up if needed and stay on the free plan. If sidebar sign-in fails, open ChatGPT or Gemini in a separate tab.
  3. Explicitly share the relevant code cell, error, page text or screenshot. Do not assume the assistant can see the whole notebook. Ask: “Explain this code in simple words, then suggest one small change. Show the complete replacement cell.”
  4. Read the proposed change, copy it into a new Colab code cell, run it yourself, and check the water balance and results. The sidebar is not a verified way to edit or run Colab automatically. Use only the public course examples when trying a new AI service.

The same prompts work in a separate ChatGPT or Gemini tab. For the reservoir-and-two-farms exercise, also provide the TaqSim API card / Русский, so the assistant uses the course's model version. The workshop demonstration uses Gemini in Colab; AI Sider is an optional alternative interface.

Three kinds of material

Every step offers up to three things. The table below always names them the same way:

  • Read: coursebook. A complete text with learning objectives, the background of the Zarafshan basin, the data and where they come from, the model, worked results and a reference list, as a web page with every figure in place. Nothing to run, no account needed.
  • Run: notebook. The same text in Colab, with the code behind it, folded until you want to see it. Change a number, run again, see what happens. Needs a Google account.
  • Play: game. An interactive web page: you move the levers, the results appear immediately. No code, no account. There are five games: TaqSim block by block (step 2), the reservoir game (step 3), the river for nature (step 4) and the Zarafshan in sixteen blocks (step 5), plus an optional annual Amu Darya demonstration.

Languages. Coursebooks switch between English, Russian and Uzbek. Notebooks have English and Russian links; step 3 also has an Uzbek notebook. The interactive block coursebook is English only. Some figures have English labels with translated captions. EN = English, RU = Russian, UZ = Uzbek.

Data. Open the course data folder.

If something goes wrong

  • A box shows red text and stops. Read the last line of the red text. Then paste the whole red text into Gemini and ask "what went wrong?". This is also how you will work during the course.
  • "Runtime disconnected". Colab stops a notebook after a while without use. Choose Runtime → Run all again.
  • The setup box takes very long. Wait two minutes. If nothing happens, choose Runtime → Disconnect and delete runtime, then Runtime → Run all.
  • Gemini does not appear. It needs a personal Google account and is not available in every country. Use the free Gemini app or ChatGPT in another browser tab instead: paste the cheat sheet from the starter notebook and your question there, and copy the code back into Colab.

What is in the folder

  • gemini/: the blank-notebook demonstration guide, checks and optional challenge.
  • src/zarafshan_taqsim/: the Zarafshan model code the notebooks use.
  • data/ZRB_baseline/: the inflow, demand, reservoir and canal data, 2010 to 2023.

Курс TaqSim: распределение воды в бассейне Зарафшана

TaqSim — программа на Python для моделирования распределения воды: соедините притоки, водохранилища, каналы и потребителей и проследите, куда идёт вода и кому её не хватает. Курс использует TaqSim v0.1.4 через тетради и игры.

Если что-то пошло не так

  • В блоке появился красный текст, и он остановился. Прочитайте последнюю строку красного текста. Затем вставьте весь красный текст в Gemini и спросите «что пошло не так?». Так же вы будете работать и во время курса.

  • 00_starter.ipynb … 06_gemini_rescue.ipynb: тетради курса. Следуйте таблице выше; исходная нумерация файлов сохранена.
  • gemini/: руководство для демонстрации с пустой тетради, проверки и необязательное задание.
  • src/zarafshan_taqsim/: код модели Зарафшана, который используют тетради.
  • data/ZRB_baseline/: данные о притоке, водопотреблении, водохранилищах и каналах, 2010–2023.
  • eflow_game/: модель, стоящая за тетрадью и игрой «вода для реки», с заранее рассчитанными результатами.
  • coursebooks/: пять учебников в виде веб-страниц, для чтения без запуска.
  • games/: пять игр.
  • _cache/: результаты долгих расчётов, чтобы тетрадь по оптимизации открывалась за секунды.

TaqSim kursi: Zarafshon havzasida suv taqsimoti

TaqSim — suv taqsimotini modellashtiradigan Python dasturi: oqimlar, omborlar, kanallar va isteʼmolchilarni ulab, suv qayerga borishi va kimga yetmasligini kuzatasiz. Kurs daftarlar va oʻyinlar orqali TaqSim v0.1.4 dan foydalanadi.

Tayyorlash · Kurs qadamlari

Xush kelibsiz. Bu papkada kursning amaliy qismi uchun kerak boʻlgan hamma narsa bor. Mashqlar brauzerda, Googlening bepul Colab xizmatida bajariladi. Kompyuteringizga hech narsa oʻrnatish shart emas.

Kursdan oldin: uchta ish (15 daqiqa)

1. Google hisobini oching. Gmail manzilingiz boʻlsa, undan foydalanishingiz mumkin. Boʻlmasa, accounts.google.com sahifasida yarating. Google tasdiqlash uchun telefon raqamini soʻrashi mumkin.

2. Birinchi daftarni oching. Shu tugmani bosing:

Matn va kulrang kod bloklari boʻlgan sahifa ochiladi. Bu daftar (notebook). Har bir kulrang blok ishga tushirish mumkin boʻlgan bitta qadam.

3. Ishga tushiring. Yuqoridagi menyudan Runtime → Run all ni tanlang. Birinchi blok model dasturini oʻrnatadi, bu bir daqiqacha vaqt oladi. Soʻng kichik daryo tizimining chizmasi, jadval va grafik paydo boʻladi. Ularni koʻrsangiz, kursga tayyorsiz.

Agar Colab daftar Google tomonidan yozilmagani uchun «Run anyway?» deb soʻrasa, Run anyway ni bosing. Bu odatiy hol.

Sunʼiy intellekt yordamchisini sinab koʻrish (10 daqiqa, ixtiyoriy, lekin tavsiya etiladi)

Colab ichida Gemini nomli yordamchi bor. Kursda siz u orqali suv modellarini oddiy soʻzlar bilan tasvirlab oʻzgartirasiz. Sinab koʻrish uchun:

  1. Sahifaning pastidagi koʻk Gemini tugmasini bosing.

  2. Shu jumlani chatga nusxalab yuboring (inglizcha boʻlsa ham boʻladi):

    Find the smallest canal share, in steps of 1 percent, for which the farm has no shortage in any of the three years. Use the run() function.

  3. Taklif qilingan kodni oʻqing. Accept and execute kodni kiritib ishga tushiradi; Accept faqat kiritadi; Deny rad etadi. Ayrim interfeyslarda Insert bor. Kodni + Code orqali nusxalab, ishga tushirish ham mumkin. Toʻgʻri javob — 9 foiz.

Shu ishlagan boʻlsa, kurs uchun kerak boʻlgan hamma narsani qildingiz. Gemini uchun boshqa topshiriqlar daftarning oʻzida bor.

ChatGPT va ixtiyoriy AI Sider yon paneli

ChatGPT va Gemini veb-versiyalari Oʻzbekistonda rasman qoʻllab-quvvatlanadi. OpenAI mamlakatlar roʻyxati va Google mamlakatlar roʻyxatini koʻring. Bu mamlakat qoʻllab-quvvatlanishini bildiradi, ammo seminar joyidagi Wi-Fi orqali ishlashini tasdiqlamaydi: VPNsiz ulanish va kengaytmani oʻrnatishni seminardan oldin joyida tekshirish kerak.

zenttranslate taqdim etgan AI Sider: ChatGPT + DeepSeek + Gemini kengaytmasidan foydalaning. Chrome uchun bu ixtiyoriy kengaytma daftar yonida AI xizmatlarining oʻz saytlarini ochadi. U Sider.ai mahsulotidan farq qiladi. Kengaytma uchun alohida hisob kerak emas; tanlangan AI xizmati hisobiga kiring. Bepul ChatGPT hisobi odatiy ChatGPT imkoniyatlarini uning standart cheklovlari bilan beradi. Mashqlar uchun pulli obuna yoki API kaliti kerak emas.

  1. Kompyuterdagi Chrome orqali aynan shu AI Sider kengaytmasining sahifasini oching, nashriyotchi zenttranslate ekanini tekshiring, Add to Chrome ni bosing va soʻralgan ruxsatlarni koʻrib chiqing. Kengaytma allaqachon oʻrnatilgan boʻlsa, uni kengaytmalar menyusidan (pazl belgisi) oching.
  2. Colab daftari yonida panelni oching, ChatGPT yoki Gemini ni tanlang va tegishli xizmat hisobiga kiring. ChatGPT uchun kerak boʻlsa Sign up ni tanlab, bepul tarifda qoling. Panel orqali kirish ishlamasa, ChatGPT yoki Gemini ni alohida brauzer varagʻida oching.
  3. Kerakli kod bloki, xato xabari, sahifa matni yoki ekran tasvirini yordamchiga aniq yuboring. U butun daftarni koʻryapti deb oʻylamang. Soʻrang: «Kodni oddiy soʻzlar bilan tushuntir, bitta kichik oʻzgarish taklif qil va almashtirish uchun toʻliq kod blokini koʻrsat».
  4. Javobni oʻqing, kodni yangi Colab blokiga nusxalang, oʻzingiz ishga tushiring va suv balansi hamda natijalarni tekshiring. Bu panel orqali Colab kodini avtomatik tahrirlash yoki ishga tushirish tekshirilmagan. Yangi AI xizmatini sinashda faqat kursning ochiq misollaridan foydalaning.

Xuddi shu soʻrovlarni ChatGPT yoki Gemini ochilgan alohida brauzer varagʻida ham ishlatish mumkin. Suv ombori va ikkita xoʻjalik mashqi uchun yordamchiga TaqSim API qoʻllanmasini ham bering: shunda u kursdagi model versiyasidan foydalanadi. Seminar namoyishida Gemini Colab ichida ishlatiladi; AI Sider — ixtiyoriy muqobil interfeys.

Uch xil material

Har bir qadam uchtagacha narsa taklif qiladi. Quyidagi jadvalda ular doim bir xil nomlanadi:

  • Oʻqish: darslik. Oʻquv maqsadlari, Zarafshon havzasi haqidagi maʼlumot, maʼlumotlar va ularning manbalari, model, tahlil qilingan natijalar va adabiyotlar roʻyxati bilan toʻliq matn, barcha rasmlari bilan veb-sahifa sifatida. Hech narsa ishga tushirish shart emas, hisob kerak emas.
  • Ishga tushirish: daftar. Oʻsha matn Colab da, orqasidagi kod bilan, siz koʻrmoqchi boʻlguncha yigʻilgan holda. Raqamni oʻzgartiring, qayta ishga tushiring, nima oʻzgarganini koʻring. Google hisobi kerak.
  • Oʻynash: oʻyin. Interaktiv veb-sahifa: richaglarni siz surasiz, natijalar darhol koʻrinadi. Kodsiz, hisobsiz. Oʻyinlar beshta: TaqSim blokma-blok (2-qadam), suv ombori oʻyini (3-qadam), daryo uchun suv (4-qadam) va oʻn olti blokdagi Zarafshon (5-qadam), shuningdek Amudaryo uchun qoʻshimcha yillik namoyish.

Tillar. Darsliklar ingliz, rus va oʻzbek tillarida. Daftarlarning EN va RU havolalari bor; 3-qadamda UZ ham bor. Interaktiv bloklar darsligi faqat EN. Ayrim rasmlar yozuvi inglizcha, izohlari tarjima qilingan. EN — inglizcha, RU — ruscha, UZ — oʻzbekcha.

Agar biror narsa notoʻgʻri ketsa

  • Blokda qizil matn chiqdi va u toʻxtadi. Qizil matnning oxirgi qatorini oʻqing. Soʻng butun qizil matnni Gemini ga qoʻyib, «nima notoʻgʻri ketdi?» deb soʻrang. Kurs davomida ham shunday ishlaysiz.
